# 注册转化漏斗口径说明

9-24 评审留的行动项之一。结论还没在会上过，先记在这。

## 三版口径

| 版本 | 分子 | 分母 | 结果 |
| --- | --- | --- | --- |
| v1 | 提交表单数 | 落地页 UV | 8.2% |
| v2 | 注册成功数 | 落地页 UV | 5.7% |
| v3 | 注册成功数 | 表单页 UV | 23.4% |

## 推荐

用 v2：分子取"注册成功"，分母取"落地页 UV"。理由是 v1 把验证码失败的也算进去了，
对外汇报会虚高；v3 的分母不含没点进表单的人，容易被问。

## 待确认

- 对外材料里用哪版，等老周下周一评审会上定。
