# Pebble 轨迹追踪与可观测性规格

本文只规定任务页中可核对的执行过程。接口和存储语义见 contracts/observability.md；实现状态只写在 status.md。

## 1. 分工

**执行轨迹**回答“实际发生了什么”：用户消息、Agent 回答、每次工具尝试及其结果、用户纠正，仍保存在任务时间线中，供 Skill 复盘引用。Pebble MCP 工具和本轮开放的 Qoder 内置工具（当前为 WebSearch、WebFetch、附件 Read）都属于工具尝试。工具成功只表示调用成功，轮次结束也不表示用户目标达成。

**运行观测**回答“这一轮为什么变成这样”：输入材料是否装入、模型和工具耗时、调用次数与用量、上下文占用、压缩、权限拒绝和影响本轮结果的静默降级。观测供人排查，不作为 Skill 复盘证据，不评价 Agent 的做法。两者通过轮次和工具条目标识互相定位，不复制工具正文。

## 2. 任务页与输入框

对话时间线保持原有阅读顺序。已结束的一轮把过程条目（思考叙述与工具行）折叠成一组，组头只报这一轮的总时长，展开按时间顺序还原过程；进行中的一轮不折叠，实时可见。

**上下文标记**在输入框发送按钮左侧：只有一个占用环，环走过的长度就是已用多少；达到或超过压缩阈值时环转告警色。环上不写数字，免得常驻的比例或“未记录”占住输入框；读数只在悬停提示与无障碍名称里（有读数如「上下文已用 4.2%」，没有读数如「上下文已用 未记录」）。点开是一个只读面板，只有两样东西：

- 一行总量（「上下文已用」与原样比例）。
- 类别分解（系统提示词、工具定义、技能、对话消息、其他、压缩预留）各占窗口多少，颜色与顺序按运行时给出的类别走，多出来的类别沿用运行时标识，不猜语义。

面板不写阈值、口径与时间点，也不折算 token：读数是最近一轮结束时本地运行时报出的窗口占用比例，不是逐 token 统计。

**只记录、不在界面展示**：材料装配与跳过明细、异常概览（被拒绝的调用、压缩、静默降级、仍在进行的调用）、用量读数与逐请求明细。它们照旧写入本地观测（§3、contracts/observability.md §2–3）；恢复展示其中任何一项都要先改本节与契约。

工具参数和返回内容只在时间线的工具行里展开；运行观测只显示比例、时长与引用，不复制工具正文。邮件发送和日程创建的最终状态继续从 Confirmation 的既有记录读取，不复制一份结论。

过程区读起来是“一段经过”，不是回答的一部分：折叠分组里的思考叙述小一号、用次要色，行距与相邻工具行同为紧凑一档，过程区内部不出现整档的空隙；正式回答保持正文字号与正文色。运行中的轮次不折叠，叙述同样按过程样式显示，与紧随其后的工具行连成一段。

## 3. 记录边界

- 随任务自动记录，只保存在单实例本地 SQLite；删除任务时一起删除。观测写入失败只记进程日志，不中断对话、工具或外部写入；读取面把缺失保留为空值，界面显示“未记录”，不推断“没有发生”。
- 观测不存提示词、材料全文、工具参数或返回正文、附件内容、凭证、SDK 原始选项、MCP 端点路径及其一次性令牌。材料只存类别、字符数和装配／跳过状态；降级只存类别与必要的计数或标识。
- 不新增独立的 Agent 循环，不改变工具可见范围、授权、Confirmation 或 Skill 复盘规则。

## 4. 验收

1. 用真实 Qoder CN SDK 分别调用 Pebble MCP 工具与成功的内置工具，确认轨迹有且只有一条对应调用，参数、结果、状态和顺序正确；观测步骤与之一一对应（步骤清单不在界面展示，按存储与读取面核对）。内置工具失败与实际到达权限回调的拒绝也能区分，拒绝在存储里记为 denied。
2. 一轮带材料的任务能核对实际装配与跳过情况；构造技能未装配和记忆判断失败，主回答继续，观测里能解释原因（界面只显示时长与上下文）。
3. 真实运行一轮并触发一次压缩，核对 SDK 回报的时长、调用次数、每次模型请求的用量与上下文占用（用量只在存储与读取面核对，界面不展示）；相邻轮累计差值推算的本轮合计与请求级求和分别核对，会话累计值本身不冒充单轮消耗。同时核对本轮记录的类别分解与本地 CLI `/context` 视图一致。
4. 运行中、刷新后和服务重启后，已记录的步骤与轮次状态一致；缺失数据标“未记录”。观测数据里搜不到正文、凭证与工具端点令牌；删除任务后观测记录消失。上下文标记在刷新与服务重启后读数一致，不随页面重开丢失。

官方 Python SDK 文档列出 PreToolUse、PostToolUse、PostToolUseFailure 回调及成功调用的工具返回字段；本地 qodercn-agent-sdk 1.0.14 也声明了这些类型。它们说明存在接入路径，**不代替第 1 项的真实 CN 运行时验收**：[Python SDK 参考](https://docs.qoder.com/cli/sdk/references-python)、[CLI 工具回调](https://docs.qoder.com/cli/hooks)。用量字段的不同口径见 [Cost and usage](https://docs.qoder.com/cli/sdk/cost-usage)。
