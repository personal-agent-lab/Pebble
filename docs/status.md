# 实现状态与已知偏差

本文件是唯一的状态记录：规格文档（`spec.md` 与各域文档）只写"应该是什么"，实现状态与已知偏差只写在这里。实现发生变化时更新本文件。

_更新于 2026-09-28，随文档重写建立的基线。_

## 总体

- 六个域（邮件、日历、记忆、资料库、技能、可观测性）与总纲描述的行为均已实现，有后端 pytest 与前端 Vitest 覆盖；三个外部边界（SDK 子进程、Gmail 投递、iCloud CalDAV）在自动化测试中使用替身。
- 部署形态：本机回环监听 + Tailscale Serve 远程访问（不使用 Funnel）；前端由后端同源托管。

## 测试基线

- 后端：`uv run --project server pytest -c server/pyproject.toml`（仓库根执行）。
- 静态检查：`ruff` 须显式 `--config server/pyproject.toml`。
- 前端：`web/` 内 `npm run typecheck && npm test && npm run build`。
