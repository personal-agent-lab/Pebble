# 记忆（Memory）规格

记忆域让助手在会话之间记住用户的个人情况与长期约定。记忆只保存、整理和提供信息，**不执行任何外部操作，也不记录出处**（不标"这条来自哪次对话"）。全局规则见 `spec.md` §4。

## 1. 定位与范围

- 记忆是两个容量受限的 Markdown 文件，由模型判断与整理，不由用户手工维护格式。
- 每轮全文注入两个文件作为常驻材料——记忆是"必须始终生效"的内容，不做按需检索。
- **前台 Agent 永远不能修改记忆**。写入只发生在两条独立的后台路径（§3），各用一次性专用会话完成。
- 不做版本管理：记忆没有历史版本可回溯，整理即覆盖。

## 2. 概念与数据

| 概念 | 含义 |
| --- | --- |
| `USER.md`（"关于你"） | 画像：用户与其生活世界的陈述性事实——身份、背景、家庭与身边人、稳定的个人偏好。判据：只是让助手了解用户，不含对助手行为的要求。上限 **1375 字符**。 |
| `MEMORY.md`（"事实与约定"） | 约定：用户确立、需要助手今后遵守或记住照办的规则、约束、承诺、默认做法。判据：话里带着对助手行为的期待。上限 **2200 字符**。 |
| 行锚点（anchor） | 编辑协议：每行带短锚点标记，编辑操作按锚点定位（新增 / 插入 / 替换 / 删除 / 移动）。 |
| 版本号 | 内容的规范化哈希，仅用于管理页的乐观并发（整篇保存时防覆盖），不是历史版本。 |

规则：

- 两个文件是自由格式的 Markdown，内容组织由模型决定。
- 分区判据是这句话在做什么，不是说谁：陈述性背景进 `USER.md`，对助手提出的要求与双方形成的约定进 `MEMORY.md`；一句话兼有背景与要求时整条进 `MEMORY.md`（必要背景写进那一条），背景后来升级为要求时由回顾跨分区移动。
- 文件上限就是每轮注入预算（见 `spec.md` §6）：记忆写满即满，不存在"超了放别处"。
- 写入是原子批量：一次整理的所有行操作要么全部生效、要么全部不生效；锚点过期（内容已被其他路径改过）时操作失败并返回最新锚点视图，由模型重读后重试，不盲写。

## 3. 写路径

两条路径都是**无状态的一次性模型会话**，会话里只有记忆编辑工具，没有其他任何工具；前台对话 Agent 与它们隔离。

### 3.1 轮内判断（judge）

- 每个用户消息轮**开始时并行**触发，回顾最近若干轮（默认 5 轮）的对话。
- 只保存**明确陈述的长期信息**（"我周二习惯早起"）；推测、临时信息、一次性的内容不保存。
- 判断为"没有值得保存的"就不调用工具，静默结束。
- 失败不重试，记为降级步骤，不影响当轮对话。

### 3.2 周期回顾（review）

- 每个任务每完成若干轮（默认 5 轮）触发一次，回顾自上次整理以来的窗口。
- 负责整理而非只新增：合并重复、更新过期、删除失效、跨分区移动。
- 有发起来源标记（周期 / 手动）；重启时中断的回顾被标记，不冒充完成。
- **用户可见提示"已整理记忆"只在发生破坏性变更（替换、删除、移动）时出现一次**；纯新增不打扰用户；失败不提示。

## 4. 注入

- 每轮把两个文件全文作为"关于你"与"事实与约定"材料注入，位于其他材料之前。
- 恢复既有会话时注入的是当轮最新内容，不是会话创建时的快照（`spec.md` §6）。

## 5. 存储与持久化

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| `USER.md` / `MEMORY.md` | 实例数据目录 `memory/` | 原子写入；**刻意排除在任何 Git 仓库之外**（包括实例数据目录的本地仓库）。 |
| 回顾任务与状态 | SQLite | 排程、窗口、状态（待运行 / 运行中 / 完成 / 失败 / 中断）。 |

## 6. 失败与降级

| 情形 | 行为 |
| --- | --- |
| 轮内判断失败 | 记为降级步骤（`memory_judge_failed`），不重试、不提示用户。 |
| 周期回顾失败 | 记录失败状态，等待下一个周期，不提示用户。 |
| 管理页并发保存冲突 | 返回冲突错误与新版本，用户重新加载后保存，不覆盖。 |

## 7. Web 界面

- 记忆管理页分两栏展示两个文件全文，可直接编辑整篇保存。
- 字符水位表（达到 90% 视为接近上限）；整篇保存带乐观并发校验。

## 8. 验收标准

1. 前台对话的工具列表中不出现记忆编辑工具；邮件触发轮也无法改写记忆。
2. 只在明确陈述长期信息时写入；推测性内容不入库。
3. 纯新增的整理不产生"已整理记忆"提示；替换 / 删除 / 移动恰好提示一次。
4. 锚点过期的编辑批次整体失败，不产生部分生效。
5. 两个文件注入长度分别不超过各自上限。
6. `memory/` 不被实例数据目录的本地 Git 仓库跟踪。
