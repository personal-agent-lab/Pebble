# Skills 本地收尾验收

本文记录 2026-09-19 的验收结果；其中“三个不同成功任务”的总结门槛已被后续用户指定单次工作的流程取代。当前行为见 `contracts/skills.md` 与 `status.md`。

2026-09-19。范围：接续导出进度中的 Skills 前端、受控加载、自动总结与测试；不扩展到 Memory、个人知识库或远程认证。

## 已完成

- `/skills` 创建、搜索、编辑、启停、归档、待审核列表、依据查看、正文对比和版本恢复。
- 新任务与回复输入框多选、移除并排除、自动匹配开关、每次发送绑定版本。
- 手动正文装配与自动按需读取；受控目录验证状态、哈希、排除项；记录实际加载来源与版本。
- 草稿内容哈希、审核版本冲突、正式版本不被未审核建议覆盖、重复批准不重复发布。
- 文件写锁、跨进程锁、Git 指定路径提交、失败回滚和未完成写入恢复。
- 最小工具证据与三个不同成功任务的序列核验；同名同来源待审核建议去重。
- 修复 Skills 错误 HTTP 映射、归档列表、任务删除外键关联、macOS 临时目录路径别名问题。

## 浏览器验证

使用独立临时数据目录 `/tmp/pebble-skills-preview`、无模型或外部服务依赖的 create_app 测试服务。
浏览器实际创建 Skill、保存启用、回到新任务页并选中；检查桌面及 390×844 手机尺寸的管理页和选择面板。
未触碰真实实例的技能、邮件或日历数据。

## 明确边界

- Qoder SDK 客户端与外部账号在自动测试中使用替身。本轮没有实际调用付费模型、发送邮件或创建日历事件。
- 采用材料装配和 skill_read 作为可验证加载路径，SDK 配置发现仍关闭；加载审计不等于模型执行成功。
- 已有会话中的历史 Skill 文字无法抹除，但后续目录与工具读取重新校验。
- 自动建议仍由模型判断；程序只核验工具序列与状态，不声称判断目标语义或“无重复纠正”。Memory 尚未实现。
- 远程认证与 HTTPS 属于原项目未完成的独立范围。此处完成的是 Skills 本地功能与验收。
