- 新建 `server/skills/service.py`（`SkillService(repository, db_path)`）：

## 关键设计取舍（评审要点）

1. **revision 单一概念**：内容 SHA-256 同时作 `expected_revision` 与版本列表 revision（git log 重构内容后计算），避免两套版本号。
2. **归档/managed 切换写文件并 git 提交，但不建 SkillChange、不升 revision**（契约 §2）。
3. **手动选择只传 id，服务端发送时绑定当前 revision**（契约 §6"发送时绑定"），Picker 无需过期处理。
4. **skill_view 记 load 但仍为 READONLY**：使用记录是内部簿记，非模型可见副作用。
5. **审批 UI 建好但无生产者**：proposed 只可能来自 D 的复盘，现以桩数据测交互，D 落地后前端零改动。
6. `skill_manage` 对 managed=false 技能直写的合法性由"仅用户发起轮可见"保证（契约 §5 例外）。
